Put the TBK-Micro product photos in this folder.

Then add each file to `src/project.ts` inside `model.photos`, for example:

```ts
{ source: '/images/keyboard/tbk-micro-detail.webp', alt: 'Close-up of the keyboard OLED and keycaps' }
```

WebP or JPG images around 1600px wide work well. The first image is shown immediately; additional images crossfade automatically and can be changed with the arrow buttons.
